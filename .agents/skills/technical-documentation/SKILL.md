# Technical Documentation Skill

## Purpose
Maintains clear, accurate, and actionable documentation covering architecture, hardware assembly, pinouts, network protocols, and troubleshooting.

## Document Requirements
- `docs/ARCHITECTURE.md`: High-level system architecture, data flow diagrams, edge-to-cloud topology.
- `docs/HARDWARE_CONNECTIONS.md`: Detailed wiring tables, GPIO assignments, voltage levels, pull-up/down notes, diagnostic bug explanations.
- `docs/MQTT_PROTOCOL.md`: Exact JSON schemas, topics, QoS levels, retain flags, and examples.
- `docs/API_DOCUMENTATION.md`: Complete OpenAPI/REST specification with sample request/response payloads.
- `docs/DATABASE_SCHEMA.md`: MongoDB collections, field types, indexes, and retention policy.
- `docs/TROUBLESHOOTING.md`: Step-by-step diagnostic workflows for ESP32, MQTT, network, and sensor anomalies.
